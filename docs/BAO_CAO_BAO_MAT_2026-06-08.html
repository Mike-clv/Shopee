Báo cáo bảo mật - 2026-06-08

Audit nhanh nhưng có xác minh production

Kết luận nhanh

Web hiện tại chưa có dấu hiệu bị bypass admin ngay lập tức, nhưng đang có một số lỗ hổng quan trọng cần xử lý sớm: lộ dữ liệu nội bộ qua API public, endpoint analytics có thể bị spam, login admin chưa có rate limit, upload SVG cùng origin, và thiếu một số security headers cơ bản.

Phát hiện chính

1. Public API exposure của dữ liệu nội bộ

Mức độ: Cao

Route GET /api/:resource đang cho phép đọc nhiều bảng dữ liệu mà không cần auth admin. Trên production, endpoint blog trả cả bài draft và endpoint sync logs trả dữ liệu log nội bộ.

2. Analytics có thể bị spam công khai

Mức độ: Trung bình cao

Các endpoint POST /api/click-events và POST /api/copy-events không yêu cầu auth và có thể làm sai số liệu click/copy.

3. Login admin chưa có rate limit

Mức độ: Trung bình

Đăng nhập admin hiện dựa trên cặp email/password trong env và chưa có lockout, throttle, captcha hoặc MFA.

4. Upload SVG cùng origin

Mức độ: Trung bình

SVG đang được chấp nhận upload và được phục vụ trực tiếp cùng origin, làm tăng bề mặt XSS nếu có file độc hại.

5. Thiếu security headers cơ bản

Mức độ: Trung bình thấp

Production có HSTS nhưng chưa thấy CSP, X-Frame-Options, X-Content-Type-Options và Referrer-Policy.

6. Advisory XSS trong react-quill/quill

Mức độ: Trung bình thấp

npm audit --omit=dev đang báo advisory XSS cho chuỗi phụ thuộc react-quill / quill.

Ưu tiên xử lý

  • Khóa public API cho draft, log và analytics
  • Thêm rate limit + validation cho analytics và login
  • Tắt upload SVG hoặc phục vụ từ origin tách biệt
  • Bổ sung bộ security headers chuẩn
  • Lên kế hoạch thay hoặc nâng cấp editor phụ thuộc Quill
